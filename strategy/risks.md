# Key Risks & Mitigations

| Risk                                                                                                                          | Mitigation                                                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Otopic dev time stolen by Sapilon emergencies                                                                                 | Ring-fenced engineering hours per week, protected from reallocation. A revenue-percentage rule funds Otopic R&D.                                                                                                   |
| One client's needs warping the core product                                                                                   | Microservice isolation + the 3-client promotion rubric ([`./governance.md`](./governance.md)).                                                                                                                     |
| Pricing model mismatch between segments                                                                                       | Two pricing motions, not one: hosted SaaS (Free/Pro) for SME teams, PAYG (Sovereign) for enterprise.                                                                                                               |
| BYOC operational complexity                                                                                                   | Heavy investment in deployment automation (Terraform/CDK) **before** scaling the Sovereign tier.                                                                                                                   |
| Free users diluting the AI-native positioning                                                                                 | Free tier _includes_ AI (rate-limited), so every user experiences the differentiator on day one.                                                                                                                   |
| The agent leaks across a sharing boundary — one client sees another client's topic. Fatal for the client-collaboration wedge. | The agent searches and answers only over what the asker can see; scoping is tested before launch, not after. Answers cite their sources, so a wrong one is visible. ([`../product/agent.md`](../product/agent.md)) |
| "Unlimited AI" on Pro turns heavy users margin-negative                                                                       | Only answers count as AI actions; a fair-use limit on Pro; measure AI cost per active user in Phase 1 before fixing the Pro price.                                                                                 |
| "Ask your workspace" is commoditised (Microsoft 365 Copilot, Slack AI, Atlassian Rovo, Notion AI)                             | Compete on what incumbents can't copy cheaply: text-first topics → cited, accurate answers; AI running in the customer's cloud; clients asking the topic themselves.                                               |
| Voice is a demo hit that goes unused                                                                                          | Talk is a second way into the same agent, not a separate feature; track talk-mode retention on its own and keep it cheap to maintain.                                                                              |
| AI calls leave the customer's boundary, breaking the Sovereign promise                                                        | Sovereign deployments run the agent's AI inside the customer's own cloud; no agent capability may depend on an outside AI service.                                                                                 |
